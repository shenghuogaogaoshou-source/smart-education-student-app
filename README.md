# 数智教育学生端页面初版

这是依据已确认产品讨论搭建的独立移动端 Web 交互原型。它与仓库中的 `zhichu_ai_school/` Flutter 工程完全分离，没有导入旧工程代码或吉祥物素材。

## 运行

在本目录执行：

```powershell
npm install
npm run dev -- --host 127.0.0.1
```

终端会输出本地预览地址。生产构建和测试命令：

```powershell
npm test -- --run
npm run build
```

## 初版已实现

- 登录前切换小学端或中学端，两端使用不同的临时主题令牌和适龄文案。
- 登录、注册、忘记密码和未满 14 周岁监护人授权页面。
- 首页、知识、测试、我的四项底部导航。
- 首页的搜索、识别工具面板、AI 通识资讯、五个精选游戏、继续学习和成果展示。
- 知识与测试页面明确显示“等待开发中”。
- “我的”页面完整布局：个人资料、学习概览、成长安排、五维成长画像、称号、勋章积分商城、学习工具、C4作品工作台和设置入口。
- A1分层设置页，包括字体切换、学段确认、通知选择、AI位置恢复和退出确认。
- 标记为“AI”的临时悬浮入口，支持拖动、单击语音面板、长按聊天面板和分级风险演示。
- 点赞、收藏、字体、学段、通知和AI位置使用浏览器本地状态。

## 仅作结构演示的能力

本原型没有连接真实账号、验证码、摄像头、图片识别、扫码、语音、大模型、云同步、内容审核、作品发布、排行榜、支付或商城交易服务。相关按钮会明确说明“页面初版尚未接入”，不会伪造成功结果。

AI 宠物最终形象和服饰素材由用户后续提供；当前悬浮按钮不是最终角色设计。

## 隐私边界

原型不会把密码、验证码、出生日期、手机号、邮箱或监护授权表单值写入 `localStorage`。演示偏好可通过清除浏览器站点数据移除。
