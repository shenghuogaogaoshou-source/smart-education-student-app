# 智芽 · 数智教育学生端

面向小学 1—6 年级的数智教育学习应用。项目将课程、闯关、AI 伙伴和创意作品连接在同一个移动端体验中，并内置“脑洞放映厅”和“创造模块”两个可独立运行的创作子应用。

## 启动

在当前目录执行：

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 5175 --strictPort
```

该命令同时启动四个进程：

- 智芽主应用：`http://127.0.0.1:5175/`
- 脑洞放映厅：`http://127.0.0.1:5191/`
- 创造模块：`http://127.0.0.1:5192/`
- AI 代理：`http://127.0.0.1:8787/`

两个游戏随智芽一起启动，但不会自动打开浏览器。学生从首页点击游戏卡片后，游戏会在智芽应用框内打开；返回后回到首页原来的滚动位置。

## 作品流程

1. 在脑洞放映厅选择“保存到智芽·我的作品”，或在创造模块打开“作品与导出”后选择保存到智芽。
2. 游戏作品先进入“我的作品 → 草稿”。
3. 学生能在“我的作品”中发布、撤回、设为仅自己或删除。
4. 发布后，作品会出现在首页成果展示、“更多作品”、作品详情和“我的收藏”中。
5. “保存到本地”是独立动作；两个游戏仍可下载自己的作品文件。

作品文件与元数据保存在当前浏览器的 IndexedDB 中，并按本地演示账号隔离，不会上传到云服务器。外部上传不限制格式：图片、视频、音频、文本和 PDF 使用安全预览，其他格式只显示文件卡与下载按钮，不会执行文件。

## 本地数据

- 学习进度与演示偏好保存在 `localStorage`。
- 作品元数据和文件 Blob 数据保存在 IndexedDB 数据库 `zhiya-works`。
- 清除当前站点的浏览器数据会同时清除本地作品、收藏和互动记录。
- 项目不会在浏览器本地保存密码、验证码、出生日期、手机号、邮箱或监护人授权表单值。

## 已实现

- 登录、注册、找回密码与未满 14 周岁监护人授权流程。
- 首页、知识、测试、我的四项底部导航，以及 1–2、3–4、5–6 年级的课程分组。
- 知识课程的漫画、图文与视频学习入口；测试的主题闯关地图、进度与奖励反馈。
- 我的页面中的成长安排、能力画像、称号、勋章、错题本、作品工作台和设置入口。
- 积分商城与“我的搭配”，支持四种 AI 伙伴形象、服饰和装饰，并同步到登录页、应用内伙伴和测试地图。
- 基于八方向透明 WebP 与分层动作的 2.5D 伙伴：支持换装、伪 360°查看、自然登录过渡和安全区悬浮。
- AI 伙伴支持轻点互动、长按语音问答、账号级朗读偏好和受保护的应用内命令；重要操作必须屏幕确认或输入当前会话密码。
- 积分、勋章、学习进度和偏好使用浏览器本地状态保存，便于原型演示。
- “脑洞放映厅”和“创造模块”在应用框内打开，支持作品草稿、发布、点赞、收藏、受限留言和外部作品上传。

## 原型边界

本项目目前仍使用前端交互与按账号隔离的本地演示数据：真实账号服务、验证码、摄像头、扫码、云同步、支付及生产级内容审核需要在后续接入后启用。作品审核目前只执行基础文字与文件类型安全检查，不声称识别所有媒体画面；真实跨设备账号同步、多用户公共社区和云端大文件存储仍通过作品仓库、审核服务与消息桥接口预留升级位置。

## 隐私边界

原型不会把密码、验证码、出生日期、手机号、邮箱或监护授权表单值写入 `localStorage`。演示偏好可通过清除浏览器站点数据移除。

`npm run build` 会先构建智芽，再把两个游戏分别输出到 `dist/embedded-games/brain-film/` 和 `dist/embedded-games/creative-module/`。
