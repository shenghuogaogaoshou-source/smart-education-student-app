# 智芽 · 小学 AI 通识教育应用

智芽面向小学 1—6 年级，把课程学习、主题闯关、AI 伙伴、相机工具和创意作品整合为一套可在 Web 与 Android 中运行的学习原型。

## 项目背景与定位

项目服务小学阶段的 AI 与数智素养启蒙，强调适龄表达、动手创造和可解释反馈。仓库公开用于学习、研究、评审及非商业协作；它不是已上线的生产教育服务，也不替代学校、教师或监护人的专业判断。

## 核心学习闭环

1. 从首页或知识页选择课程，完成漫画、图文或视频学习。
2. 在测试地图中通过主题关卡，用即时反馈巩固知识。
3. 由 AI 伙伴提供受限提示、朗读和应用内导航，重要操作仍需屏幕确认。
4. 在“脑洞放映厅”或“创造模块”中形成作品草稿，发布到本地作品中心。
5. 通过成长记录、错题、积分和勋章回顾学习，再进入下一轮任务。

## 三学段课程

- 1—2 年级：以观察、识别、规则意识和具象互动为主。
- 3—4 年级：引入信息组织、问题拆解、工具使用与协作表达。
- 5—6 年级：加强 AI 原理、数据意识、创作实践和责任判断。

三个学段使用统一的 S 形闯关路线，并保留各自的课程主题、进度和场景反馈。

## AI 伙伴、相机工具与创意工坊

- AI 伙伴支持轻点互动、长按语音问答、朗读偏好和受保护的应用内命令。
- 相机与识别入口用于拍照识题、文字识别和扫码原型，具体边界见[识别工具文档](docs/recognition-tools.md)。
- “脑洞放映厅”和“创造模块”以内嵌应用运行，作品可保存为草稿、发布、撤回或导出。
- 外部文件仅经过基础文字与文件类型检查；安全预览不会执行未知文件。

## 儿童安全与隐私

原型不把密码、验证码、出生日期、手机号、邮箱或监护人授权表单值写入 `localStorage`。学习进度与演示偏好保存在浏览器本地，作品文件保存在 IndexedDB；清除站点数据会同时清除这些内容。AI 对话、相机、作品审核和重要操作的限制参见[文档索引](docs/README.md)。

请勿把真实儿童个人信息、生产密钥或敏感素材用于演示。发现安全问题时按 [SECURITY.md](SECURITY.md) 私下报告，不要在公开 Issue 中披露。

## 快速启动

建议使用 Node.js 24、Python 3.12 与系统 FFmpeg。

```powershell
npm ci
npm run dev
```

`npm run dev` 会启动主应用、两个创作子应用及其本地服务。需要 AI 能力时，只复制仓库提供的 `.env.example` 模板并在本机填写；不要提交任何真实 Key。更完整的本机配置见 [`docs/deepseek-companion-setup.md`](docs/deepseek-companion-setup.md)。

## 技术架构与目录

| 路径 | 作用 |
| --- | --- |
| `src/` | React + TypeScript 主应用与课程、测试、伙伴、作品等功能 |
| `server/` | 本地开发服务、AI 代理与云网关适配 |
| `apps/` | “脑洞放映厅”和“创造模块”两个独立创作应用 |
| `packages/` | workspace 共享包，包括任务客户端与作品桥 |
| `android/` | Capacitor Android 工程 |
| `deploy/aliyun/` | 阿里云运行时与部署示例 |
| `scripts/` | 构建、打包、导入和仓库验证脚本 |
| `docs/` | 部署、AI、安全、验收、规格与实施文档 |

## 测试、构建与交付

```powershell
npm run test:all
npm run build
```

`test:all` 覆盖主应用、服务端、脚本和两个创作应用；`build` 构建主 Web 应用与内嵌游戏，并输出到 `dist/`。CI 在 pull request 及 `main` 分支 push 时使用 Node.js 24、Python 3.12 和系统 FFmpeg 执行同样的安装、测试与构建基线。

Android Release、源码包和阿里云交付说明请从[文档索引](docs/README.md)进入。

## 数据与原型边界

当前仓库仍使用前端交互和按本地演示账号隔离的数据。真实账号、验证码、摄像头权限、扫码、跨设备同步、支付、云端大文件存储及生产级内容审核需要在后续服务接入后启用。现有审核只执行基础文字和文件类型检查，不声称识别所有媒体内容。
