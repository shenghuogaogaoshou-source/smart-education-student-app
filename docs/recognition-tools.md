# 拍照与识别工具

首页相机按钮提供六个入口：拍照识物、扫码识别、文字提取、题目解析、翻译文字、内容检查。

- Web 版相机使用浏览器授权，仅在点击“打开相机”后请求；Android APK 使用系统相机采集入口。也可上传 JPG/PNG/WebP，原图上限 20 MB，图片在本地按原比例压缩到最长边 1600 像素；拍摄、返回或关闭面板后会释放视频流。
- 扫码优先通过浏览器 BarcodeDetector 在本机处理；不支持、调用失败或未识别时自动使用 ZXing 兼容解码器，支持二维码和常见商品条码。不上传扫码图片；本地读出的文字发送给千问作内容解读，不自动打开链接。
- 文字分析优先使用已配置的视觉模型；未配置时使用 `DEEPSEEK_API_KEY`。图片分析需要在 `server/.env.local` 配置 `VISION_BASE_URL`、`VISION_MODEL`、`VISION_API_KEY`，选择支持 OpenAI 兼容 chat completions、image_url 与 JSON 输出的视觉模型。BASE_URL 包含 API 前缀（例如 /v1），不要包含 /chat/completions。
- 配置后重新运行 `npm run dev`。密钥仅保留在服务端，不会发送给浏览器。服务不记录图片或请求正文。
- 未配置服务时明确提示；仅展示实际识别结果。
- 结果包含实际输出、输入线索、简明方法说明和局限。方法说明用于教学与核验，不展示模型私有推理链，不伪造百分比置信度。
- 结果支持复制和下载，默认不保存到本地存储。二维码结果仅作为文本展示。

验证：`npm test -- --run src/features/home/CameraToolSheet.test.tsx src/features/home/HomePage.test.tsx`；`node --test server/recognition.test.mjs`；`npm run build`。

真实相机需在 HTTPS 或 localhost 下授权。视觉模型需配置后进行实图验收；模型结果可能出错，内容检查不等同于联网事实认证。

拍照识物结果支持点击朗读，使用浏览器中文语音，分句朗读识别结果、依据及科普。可停止；返回、关闭或重新识别时停止播放。设备需支持 SpeechSynthesis 并安装可用语音。

文字提取、题目解析、翻译文字和内容检查均通过千问处理图片或文字，并返回与输入相关的拓展科普、知识例子与思考问题。整页材料最多生成6000 tokens，格式缺失或截断时自动重试一次（最多10000 tokens）；客户端等待上限130秒。仅记录功能、返回状态等诊断信息，不记录用户内容。

### 六种结果展示
- 拍照识物：物品观察卡、可见特征、观察方法与物品科普，支持朗读。
- 扫码识别：解码原文独立展示和复制，另列 AI 内容解读。
- 文字提取：保留原文的可编辑文本框、字符计数、复制修改稿和恢复原文。
- 题目解析：已知条件、分步解法、点击展开的答案和举一反三。
- 翻译文字：原文与译文分区、复制译文、词语表达与语言知识。
- 内容检查：检查结论、原句引用、逐项原因和修改建议。
所有展示沿用应用主题变量。翻译响应新增必需的 sourceText 字段。
