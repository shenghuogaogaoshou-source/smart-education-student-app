# Student App Initial Pages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an independent, runnable mobile-first React prototype containing the approved authentication flow, dual school-stage themes, home page, complete profile page, settings page, AI companion entry, and “等待开发中” knowledge/test pages.

**Architecture:** Create `student_app_prototype/` beside the untouched Flutter project. Use feature-focused React components, a single typed application context with local-storage persistence, React Router for navigation, and CSS design tokens selected by learning stage. External services remain explicit demo boundaries rather than simulated successes.

**Tech Stack:** React, TypeScript, Vite, React Router, Lucide React, Vitest, React Testing Library, jsdom, CSS

**Spec:** `docs/superpowers/specs/2026-08-24-student-app-initial-pages-design.md`

## Global Constraints

- Do not modify, import, or copy code or mascot assets from `zhichu_ai_school/`.
- Knowledge and test routes must only show their approved “等待开发中” states.
- Do not claim that OTP, camera, image recognition, voice, cloud sync, AI, payment, or moderation services are connected.
- Use a text-labelled temporary AI control; do not create a replacement pet character.
- All visible icons must come from Lucide React; do not use emoji, text-symbol icons, hand-built SVG, CSS art, or placeholder image boxes.
- Support elementary and secondary theme tokens, 320px width, three font scales, reduced motion, and 44px primary touch targets.
- Persist only prototype preferences and interactions in local storage; do not persist passwords, verification codes, birth dates, or guardian authorization form values.
- Git commits are attempted only if repository metadata is valid. The current `.git` points to a missing worktree directory, so implementation must not rewrite Git metadata to force commits.
