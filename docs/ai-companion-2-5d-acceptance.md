# 智芽 AI 伙伴 2.5D 验收记录

## 自动验收

- `npm test -- --run`：48 个测试文件、310 项测试通过。
- `npm run test:server`：28 项 Vitest 服务端测试与 6 项识别测试通过。
- `npm run build`：TypeScript 与 Vite 生产构建通过。
- `node scripts/validate-companion-2d-assets.mjs`：四个伙伴、52 个 WebP 分层通过。
- `npm audit`：0 个已知漏洞。
- `git grep` 长密钥模式扫描：未发现 `sk-` 长密钥。
- Three.js 与 React Three Fiber 已无源码引用并从依赖移除。

## 已覆盖的交互

- 登录页与登录后伙伴使用同一装扮快照，过渡由 1.32 秒的分阶段动作完成，尺寸连续缩放且不旋转。
- 悬浮伙伴按应用可见框、底部导航和安全区限位。
- 测试地图伙伴读取当前关卡 DOM 锚点，中心对齐并停在按钮上方 8px。
- 积分商城“我的”和 AI 对话页顶部支持八方向旋转。
- 四种伙伴、六件商品均有八方向资源；商城、登录、悬浮、对话和地图共享账号搭配。
- AI 对话页使用固定伙伴顶部、可滚动消息区和固定安全区输入栏。
- 文字、语音问题与明确的应用操作可分流；中风险显示屏幕确认，高风险要求当前会话密码。
