# 智芽异步 AI 与性能体验设计

日期：2026-10-28  
分支：`codex/async-ai-performance`  
目标 APK：`E:\智芽\运行文件\智芽.apk`

## 1. 问题与实测证据

本轮反馈集中在 AI 无回复、后台生成长期等待、语音播读慢和作品页返回样式不一致。生产环境实测结果如下：

| 能力 | 当前实现 | 实测耗时 | 主要现象 |
| --- | --- | ---: | --- |
| AI 文字回答 | `deepseek` 普通 JSON 请求 | 1.6 秒 | 模型本身不慢 |
| TTS 完整音频 | 智谱 TTS | 2.8 秒 | 每句开始时重复等待 |
| 摄像头识物 | `qwen3-vl-plus`，长边最大 1600px | 74.25 秒 | 面板长期停在“正在仔细观察” |
| 快速视觉试跑 | `qwen3.5-omni-flash`，960px 测试图 | 17.74 秒 | 简单识物结果正确，具备替代价值 |
| 创造模块实物图 | 方舟图片生成，`2048×2048` | 约 20 秒 | UI 却显示“约 10 秒” |
| 脑洞单格画面 | 方舟图片生成 | 26.42 秒 | 同步等待且离开页面后难以恢复 |

`qwen3-vl-flash` 在当前账号不可用；`qwen3.8-omni-flash` 实测约 76.56 秒。因此快速模型选择 `qwen3.5-omni-flash-2026-03-15`，高质量回退继续使用 `qwen3-vl-plus`。

登录页“已经识别出问题却不回复”不是模型响应慢。当前 Android 语音插件在手动停止后不保证触发 `listeningState=stopped`，前端可能永久停在转写阶段。需要在停止录音后增加确定性提交兜底，并处理“手指松开时插件尚未初始化完成”的竞态。

## 2. 已确认的产品决策

- AI 文字优先：先显示“已听到”，随后流式展示回答，并立即开始语音播放。
- 云端 TTS 1.5 秒内未准备好时，立即切换 Android 本机中文语音。
- 摄像头任务超过 12 秒未完成时，可自动收起为后台任务，用户继续学习。
- 摄像头、实物图、脑洞画面的任务状态必须保存；离开页面或关闭游戏后仍可恢复。
- 摄像头默认尝试 `qwen3.5-omni-flash-2026-03-15`，失败或结构化结果无效时回退 `qwen3-vl-plus`。
- 保留现有知识、测试、积分、勋章、作品和 AI 形象功能。
- 继续使用现有正式签名和 `versionCode=1`，覆盖安装保留本地数据。
- 允许同步更新香港云端。

## 3. 总体架构

采用“持久化后台任务 + 前端任务轮询 + 快速模型分级”的方案。

### 3.1 统一任务 API

新增统一的持久化任务接口：

```text
POST /api/tasks
GET  /api/tasks/{taskId}
```

创建任务：

```json
{
  "kind": "vision | product-image | film-image",
  "payload": {},
  "clientTaskId": "optional-idempotency-key"
}
```

创建成功后立即返回 `202`：

```json
{
  "taskId": "server-generated-uuid",
  "status": "queued",
  "createdAt": "2026-10-28T15:30:00.000Z"
}
```

查询结果：

```json
{
  "taskId": "...",
  "kind": "vision",
  "status": "queued | running | succeeded | failed | interrupted",
  "stage": "preparing | recognizing | rendering | packaging",
  "createdAt": "...",
  "updatedAt": "...",
  "elapsedMs": 17800,
  "result": {},
  "error": "stable_error_code"
}
```

任务状态规则：

- `queued`：服务端已接收，尚未开始。
- `running`：正在执行，附带阶段文案。
- `succeeded`：结果完整，可重复读取。
- `failed`：返回稳定错误码，可显式重试。
- `interrupted`：容器重启导致任务中断，客户端展示“重新生成”。

任务结果和元数据写入 `DATA_DIR/tasks`，采用逐文件原子写入。默认保留 24 小时，最多保留最近 100 个任务，禁止保存请求日志、Authorization、API Key 或学生隐私正文。

### 3.2 任务执行器

同一任务服务支持三种执行器：

- `vision`：调用现有 `recognize` 逻辑，返回六项识别工具的完整结果。
- `product-image`：调用现有方舟图片代理，返回图片 data URL 或 URL。
- `film-image`：调用脑洞 `/api/image`，返回脑洞使用的图片地址。

任务服务最多同时运行 4 个任务，其余排队。任务执行器不得依赖发起请求的 HTTP 连接，客户端断开后仍继续。

### 3.3 前端任务流

统一客户端接口：

```ts
type BackgroundTask = {
  taskId: string
  kind: 'vision' | 'product-image' | 'film-image'
  status: 'queued' | 'running' | 'succeeded' | 'failed' | 'interrupted'
  stage?: string
  result?: unknown
  error?: string
}
```

轮询策略：

- 前 10 秒每 1 秒查询一次。
- 10 秒后每 2.5 秒查询一次。
- 页面隐藏时停止高频轮询，恢复可见时立即查询一次。
- 同一任务只允许一个轮询器。
- 任务成功后写入本地任务记录，避免页面重载后重复提交。

任务记录使用 IndexedDB。任务记录只保存任务 ID、类型、展示标题、本地作品 ID、状态和时间，不重复保存大图。

## 4. AI 对话与语音

### 4.1 Android 录音结束

原生语音捕获增加确定性收尾：

- 记录 `stopRequested`，即使 `plugin.start()` 尚未完成，初始化完成后也立即停止。
- 调用 `SpeechRecognition.stop()` 后启动 700ms 收尾计时器。
- 收到插件 `stopped` 事件时立即提交并清除计时器。
- 计时器到期时，使用最新 partial transcript 提交；没有文本则展示“没有听清”。
- `listeningState.started` 后若超过 12 秒没有新增文本，也自动结束，避免永久占用麦克风。
- 取消与正常停止分离，取消不能提交半句话。

### 4.2 流式 AI 回答

新增流式回答端点：

```text
POST /api/companion/reply/stream
Content-Type: text/event-stream
```

事件：

```text
event: delta
data: {"text":"我是你的"}

event: done
data: {"reply":"我是你的 AI 学习伙伴。"}

event: error
data: {"error":"provider_error"}
```

前端收到第一段 delta 后：

- 立即在登录伙伴气泡或 AI 对话中显示。
- 通过 ARIA live 增量提示，不重复朗读每个 delta。
- 完整回答结束后再开始语音播放，避免朗读被频繁重播。

流开始前遇到临时网络失败允许重试一次；流已经输出内容后断开时，保留已收到文字并显示“重新回答”，不重复拼接同段内容。

### 4.3 TTS 快速回退

Android 播放流程：

1. 回答完成，立即请求云端 TTS。
2. 启动 1.5 秒计时器。
3. 云端音频在计时器前完成：播放云端音频。
4. 计时器先到：取消云端等待，立即播放 Android 本机中文 TTS。
5. 当前回答选择本机语音后，后续分段继续使用本机语音，避免每句重新等待 1.5 秒。

Web 端继续保持当前云端优先、本机兜底的行为。

### 4.4 课程跟读

- APK 原生平台使用共享快速 TTS。
- 当前段开始播放后预取下一段的云端音频。
- 如果当前会话已进入本机语音模式，后续段落直接使用本机语音。
- 切换页面、切课或应用进入后台时取消当前播放和预取。

## 5. 摄像头六项工具

### 5.1 模型与图像路由

图片在客户端按工具类型等比压缩：

| 工具 | 最大长边 | 首选模型 |
| --- | ---: | --- |
| 拍照识物 | 960px | `qwen3.5-omni-flash-2026-03-15` |
| 题目解析 | 1024px | `qwen3.5-omni-flash-2026-03-15` |
| 翻译文字 | 1024px | `qwen3.5-omni-flash-2026-03-15` |
| 内容检查 | 1024px | `qwen3.5-omni-flash-2026-03-15` |
| 文字提取 | 1280px | `qwen3.5-omni-flash-2026-03-15` |
| 扫码识别 | 本地解码 | 仅把码中文本交 AI 解释 |

快速模型返回无效结构或不可恢复的模型错误时，回退 `qwen3-vl-plus`。鉴权、输入格式和用户取消错误不触发回退。

### 5.2 页面行为

- 点击“开始”后 1 秒内进入任务进度界面。
- 12 秒仍未完成时显示“已转到后台”，自动关闭工具面板。
- 首页出现“识别中”任务卡；成功后变为“识别完成”。
- 点击任务卡恢复原结果页，结果结构与当前一致。
- 失败任务显示“重新识别”和“查看原因”，不伪造结果。

## 6. 创造模块实物图

- `generateProductImage` 改为提交 `product-image` 任务。
- 当前电路、标题、提示词和 `clientTaskId` 保存在作品草稿中。
- UI 显示“正在画 · 通常需要 20—40 秒”，不显示不准确的固定 10 秒。
- 离开检查面板或游戏后，任务继续。
- 重新进入创造模块时恢复任务：
  - 运行中：显示任务进度，禁用重复生成。
  - 成功：恢复实物图。
  - 失败或中断：显示“再次生成”。
- 同一 `clientTaskId` 重复提交必须返回同一任务，避免重复计费。

## 7. 脑洞放映厅画面

- “AI 画画”从同步 `/api/image` 请求改为提交 `film-image` 任务。
- 每个分镜保存自己的 `imageTaskId`；跨分镜可并行提交，但受服务端并发限制。
- 分镜区域显示“排队中 / 正在画 / 已完成 / 中断”。
- 用户切换步骤、关闭页面或重新打开草稿时，按任务 ID 恢复状态。
- 任务完成后把图片压缩到现有 1280px 规格并保存到草稿。
- 单格重画沿用同一任务机制；已有图片不被清空，直到新任务成功。
- AI 出图额度只在任务成功时扣减，失败或中断不扣减。

## 8. 作品展示与作品详情

`WorksGalleryPage` 和 `WorkDetailPage` 统一使用 `MobilePageHeader`。

作品展示页调整：

- 顶部为统一返回按钮、标题“作品展示”和副标题。
- “每天 / 每周 / 每年”保持分段筛选，但使用完整可点击区域。
- 前 3 个作品显示为带排名标识的精选卡片。
- 其余作品以两列紧凑卡片展示。
- 删除当前页面下方重复的“全部作品”第二套列表。
- 媒体预览、标题和互动按钮分开处理，避免在可点击容器中嵌套按钮。
- 卡片统一显示作品来源标签、作者、点赞数和收藏数。
- 手机保持两列紧凑布局；平板限制内容宽度，不把卡片横向拉伸。

作品详情页：

- 返回按钮、页头高度、安全区和标题位置与课程页一致。
- 保留现有作品预览、点赞、收藏、留言和简介内容，不改变业务功能。

## 9. 错误与安全

- 所有任务错误使用稳定错误码，原始上游响应仅写服务端安全日志。
- 日志禁止记录图片正文、学生问题、Authorization 或 API Key。
- 任务 GET 使用不可猜测 UUID，不允许列表遍历他人结果。
- 上传输入继续执行现有大小、类型和工具白名单校验。
- 对话继续使用现有儿童安全系统提示、危险问题本地拦截和儿童友好错误。
- 流式回答在输出前与完成时各执行一次安全校验；发现危险增量立即终止并隐藏未安全内容。

## 10. 测试与验收

### 10.1 自动化

- 语音停止：插件不发 stopped、初始化未完成即松手、正常 stopped、取消、超时。
- 流式回答：首个 delta、断流、重试、过期请求取消、安全拦截。
- TTS：1.5 秒内云端完成、超时本机回退、会话级本机锁定、取消。
- 任务服务：创建、轮询、并发、幂等、持久化、重启中断、过期清理、错误码。
- 模型路由：960/1024/1280px 映射、快速模型成功、快速模型失败回退、鉴权失败不重试。
- 摄像头：12 秒后台化、首页任务卡、结果恢复、失败重试。
- 创造模块：任务恢复、成功扣额度、失败不扣额度、重复提交。
- 脑洞：分镜任务并行、关闭重开恢复、单格重画、旧图保留。
- 作品页：统一页头、筛选、精选与全部布局、键盘可用性。

### 10.2 性能目标

- AI 首段文字目标 `≤ 2.5 秒`。
- 云端 TTS 未在 1.5 秒就绪时，本机语音必须开始。
- 摄像头任务创建响应目标 `≤ 1 秒`。
- 960px 安全测试图的首选视觉模型目标 `≤ 25 秒`。
- 图片生成与影片页面在提交后 1 秒内显示可恢复任务状态，不以“10 秒”误导。

### 10.3 Android 验收

- `versionCode=1` 覆盖安装后本地学习数据保持不变。
- 登录页长按语音能在松手后提交，显示流式回答并播放语音。
- 摄像头六项工具逐项提交任务；至少完成真实识物、翻译和一种 OCR 流程。
- 创造模块离开页面后任务继续，重新进入可恢复图片。
- 脑洞画面任务关闭页面后继续，重新打开草稿可恢复。
- 作品详情与更多作品页返回按钮完全一致，页面无横向溢出。
- 最终 APK 完成正式签名验证、冷启动、完整测试和唯一文件交付。

## 11. 非目标

- 不重新设计知识、测试、成长画像、积分或勋章业务。
- 不更换现有正式签名。
- 不引入 WebSocket 作为首版任务协议；HTTP 任务轮询足以覆盖当前演示规模。
- 不将所有 AI 能力本地化，也不把需要联网的生成功能包装成离线能力。
