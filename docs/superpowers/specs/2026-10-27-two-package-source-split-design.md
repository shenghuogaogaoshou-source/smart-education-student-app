# 智芽双包源码拆分设计

## 目标

把现有智芽项目整理为两个可独立解压的源码包：

- `智芽App前端.zip`
- `智芽App后端.zip`

两份源码一起运行后，功能与学生当前在本机浏览器中看到的演示保持一致。不制作后台管理系统。

## 前端范围

前端包包含：

- 学生 App 主应用。
- 登录、注册、找回密码和监护人授权。
- 首页、知识、测试、我的四个主页面。
- 学习进度、成长安排、能力画像、错题本、积分、勋章和排行榜。
- AI 伙伴、积分商城、收藏、作品管理与作品互动。
- 脑洞放映厅和创造模块的游戏前端。
- 所有课程、漫画、视频、作品、伙伴和商城静态资源。

登录状态、学习进度、积分、勋章、作品 Blob、收藏和互动继续使用 `localStorage` 与 IndexedDB，保持现有本机演示行为。

前端不包含：

- 服务端 AI 密钥。
- AI 代理实现。
- 脑洞放映厅 Python 后端。
- `node_modules`、构建产物、日志和旧 worktree。

## 后端范围

后端包包含：

- AI 伙伴回复、安全策略、伙伴指令解析。
- 语音合成、相机识别、学习安排建议。
- DeepSeek 与火山图片代理接口。
- 脑洞放映厅 Python 后端，包括剧本、分镜、图片、视频、配音、作品库和健康检查。

后端包不包含真实密钥。提供 `.env.local.example` 与 `apps/brain-film/.env.example`，使用者自行填写。

## 接口契约

- 前端主应用默认把 `/api/companion/*`、`/api/tts`、`/api/deepseek/*`、`/api/ark/*` 代理到 `http://127.0.0.1:8787`。
- 创造模块默认把 `/api` 代理到 `http://127.0.0.1:8787`。
- 脑洞放映厅默认把 `/api` 代理到 `http://127.0.0.1:8766`。
- 代理目标可通过 `ZHIYA_AI_API_ORIGIN`、`ZHIYA_CREATIVE_API_ORIGIN` 和 `ZHIYA_BRAIN_FILM_API_ORIGIN` 修改。

## 运行方式

1. 解压后端，安装依赖、配置环境变量并启动，默认监听 `8766` 和 `8787`。
2. 解压前端，安装依赖并启动，默认监听 `5173`、`5191`、`5192`。
3. 两个终端同时运行即可。

## 打包规则

- 输出目录固定为 `E:\智芽\源文件`。
- ZIP 中保留源码、测试、依赖锁、静态资源和 README。
- 排除 `.env`、`.env.local`、`node_modules`、`dist`、日志、缓存、`.worktrees` 和敏感数据。
- 打包脚本可重复执行，并在覆盖前只清理固定暂存目录。

## 验收

- 前端与后端均能在全新目录执行 `npm ci`。
- 前端测试和生产构建通过。
- 后端 Node 与 Python 测试通过。
- 后端 `8766`、`8787` 健康检查通过。
- 前端三个服务启动并返回 HTTP 200。
- 浏览器中主应用、AI 对话、脑洞放映厅和创造模块可正常打开。
