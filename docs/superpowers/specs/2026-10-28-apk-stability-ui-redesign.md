# 智芽 APK 稳定性修复与移动端排版统一设计

日期：2026-10-28  
目标分支：`codex/single-apk-aliyun`  
交付物：`E:\智芽\运行文件\智芽.apk`

## 1. 背景与目标

本轮针对已交付的单 APK 版本处理六类问题：登录页 AI 伙伴能识别语音但无法完成回答、1—2 年级课程跟读在 APK 中不可用、首页摄像头六项能力不可用、创造模块“生成实物图”返回 `502 provider_error`、多处返回按钮与页面安全区排版不统一，以及作品管理中的删除操作挤压成竖排。

目标是在保留现有功能、内容、儿童友好画风、本地学习数据和正式签名的前提下，修复功能链路并统一移动端布局规范。Web 版既有行为是课程跟读和摄像头六项能力的功能基准。

## 2. 已确认约束

- APK 包名保持 `com.zhiya.education`，使用现有正式签名。
- 按用户要求保持 `versionCode=1`；不通过清空数据规避同版本覆盖限制。
- 覆盖安装后保留学习进度、积分、勋章、作品以及其他本地数据。
- 登录页、应用内悬浮伙伴和 AI 对话页共用同一套语音问答链路。
- AI 回复同时显示在伙伴对话框中并播放语音。
- 请求失败时自动重试一次；仍失败时显示儿童友好且可操作的提示。
- 1—2 年级跟读与当前 Web 版保持一致。
- 摄像头六项能力与当前 Web 版的入口、结果和功能一致，只增加 Android 适配。
- 图片过大时自动等比压缩；权限、网络和输入错误分别提示。
- 实物图生成失败不伪造结果；自动重试一次，并允许再次生成。
- 普通二级页面统一使用浅暖色圆角返回按钮；弹窗使用右上关闭按钮。
- 页面内容、模块顺序和文案原则上不变，只修复移动端排版。
- 手机竖屏优先，平板不拉伸；视频和创意游戏允许横屏，其他页面横屏时提示旋转。
- 作品删除改为列表红色描边按钮加独立二次确认框。
- 允许同时更新香港云端服务，域名保持 `https://api.zhiyaedu.com.cn`，部署前保留回滚依据。

## 3. 方案选择

采用“共享能力层修复 + 统一移动端规范”。不在各页面复制补丁，也不进行高风险的全应用重构。

现有代码已经具备对话控制器、课程跟读 Hook、摄像头工具面板和实物图代理接口。本轮在这些公共边界定位并修复根因，再由现有页面复用修复结果。这样能减少三套 AI 入口或六项摄像头工具再次发生行为分叉的风险。

## 4. 功能架构

### 4.1 AI 语音问答

统一数据流：

`长按录音 → Android 语音识别 → 显示识别文字 → 云端 AI 回答 → 显示回答 → 播放回答语音`

登录页、悬浮伙伴和 AI 对话页调用同一控制器。状态统一为待机、聆听、转写、思考、朗读和错误；取消、页面卸载或新请求会中止旧录音、旧请求与旧播放，避免串音和过期回答。

云端回答请求只对可恢复的网络错误、超时或服务端临时错误自动重试一次。回答文字一旦成功就立即保留在对话框中，不因 TTS 失败被清除。播放优先走项目配置的云端 TTS；失败时回退 Android 本机 TTS。两种播放方式都失败时保留文字，并提供“重新回答”和“转文字提问”。权限拒绝、未听清、网络失败和服务失败使用不同提示。

### 4.2 1—2 年级跟读

保留 Web 版现有按钮、顺序、切页和高亮行为。Web 与 APK 使用相同课程段落序列和跟读状态机；仅在播放层选择适合当前平台的实现。暂停、切换课程、离开页面、应用进入后台时停止当前播放，返回页面后不自动从错误位置继续。

### 4.3 摄像头六项能力

六项功能继续使用同一个图片采集与识别适配层：

1. 请求或检查相机权限；
2. 调用后置相机或相册；
3. 修正图片方向并按比例压缩；
4. 维持 Web 版相同的请求数据结构；
5. 显示分阶段进度；
6. 将结果交给现有结果组件渲染。

权限未开启时提供开启权限指引；图片读取失败可重新拍摄或上传；网络与服务失败可重新识别。自动压缩不拉伸图片，不上传人脸、姓名、住址等明确隐私信息的提醒继续保留。

### 4.4 生成实物图

请求链路在创造模块、智芽云端网关和上游图像服务之间携带内部请求编号。云端记录上游状态码和可公开的错误类别，不记录 API Key 或儿童输入中的敏感信息。

超时、限流和临时 `5xx` 只重试一次，并使用短退避；鉴权、输入错误等不可恢复错误不重试。最终失败时保留电路作品、标题和提示词，前端显示易懂原因及“再次生成”。原始 `provider_error` 不直接展示给儿童，诊断信息保留在服务端日志。

## 5. 移动端界面规范

### 5.1 页面头部

建立共享 `MobilePageHeader`。普通二级页面使用固定触控尺寸的浅暖色圆角返回按钮，并统一处理 Android 状态栏和 `safe-area-inset-top`。标题、副标题和右侧操作使用同一网格，标题不得与状态栏、返回按钮或右侧操作重叠。

弹窗只在需要返回上一步时显示左上返回；关闭整个弹窗使用右上关闭。单层弹窗不同时显示含义重复的返回和关闭。

### 5.2 间距与响应式

统一页面左右留白、卡片垂直间距、圆角、按钮高度、标题层级、正文行高与最小触控区域。保留模块顺序和文案，只处理不自然换行、按钮挤压、内容贴边、底部导航遮挡和悬浮伙伴越界。

手机竖屏为主布局。平板采用居中限宽和可扩展内容宽度，不直接拉伸手机卡片。视频和创意游戏可进入横屏；其他页面横屏显示柔和的旋转提示。底部导航、悬浮伙伴和长页面共同使用安全区变量。

### 5.3 删除操作

作品卡片只显示红色描边“删除”按钮。点击后打开独立确认弹窗，显示作品名称和不可恢复说明；“取消”和“确认删除”横向排列，确认按钮使用危险色。删除进行中禁用重复点击；成功后关闭弹窗并刷新列表，失败时保留作品并显示可重试提示。

## 6. 数据与安全

不修改现有本地存储键及既有数据语义。新增状态采用兼容默认值，旧数据缺少新字段时仍能正常读取。修复期间禁止清空 `localStorage`、IndexedDB 或作品 Blob。

API Key、签名密码和服务器凭据只存在于服务端或受保护的本机目录。APK、前端 bundle、客户端日志和截图不得包含秘密值。

## 7. 云端部署

香港服务继续使用 `https://api.zhiyaedu.com.cn`。部署前记录当前 Git 提交、容器镜像/构建来源和环境配置哈希；不复制环境变量明文。更新后检查容器健康、HTTPS、AI 回答、TTS、六项识别入口和实物图接口。失败时按记录回滚到上一运行版本。

## 8. 测试与验收

### 8.1 自动化

- 对话控制器：识别完成、回答成功、一次重试、文字保留、TTS 回退、取消与竞态。
- 跟读：开始、暂停、切页、离开页面和平台播放选择。
- 摄像头：权限拒绝、图片方向、等比压缩、六项请求映射、超时与重试。
- 实物图：成功、可恢复 `502` 重试、不可恢复错误和作品状态保留。
- UI：共享头部、确认弹窗、删除进行态和关键响应式断点。

### 8.2 Web 回归

验证登录、首页、知识、测试、我的、AI 对话、课程跟读、摄像头六项能力和两个创意游戏。重点确认 Android 适配没有改变 Web 版既有行为。

### 8.3 Android 回归

在模拟器写入旧版学习进度、积分、勋章和作品后覆盖安装新版，确认数据仍在。验证三个 AI 入口的文字与语音回答、1—2 年级跟读、摄像头六项能力、实物图、作品删除、返回按钮、安全区及横竖屏规则。

视觉巡检覆盖常见手机宽度与 Android 平板尺寸，排除状态栏重叠、按钮竖排、卡片溢出、底部导航遮挡和悬浮伙伴越界。

### 8.4 最终交付

运行完整测试和正式构建，验证 APK 签名、安装、冷启动和云端健康。最终覆盖 `E:\智芽\运行文件\智芽.apk`，并确认该目录只有这一份 APK。

因保持 `versionCode=1`，部分 Android 安装器可能拒绝同版本覆盖。验收同时记录直接覆盖安装与 ADB 覆盖安装结果，但不得通过卸载或清除数据伪造覆盖成功。

## 9. 完成标准

- 三个 AI 入口均可完成语音提问、文字回答和语音播放。

- 摄像头六项能力逐项完成真实请求并显示结果。

- 云端健康、完整测试、签名和安装验证全部通过。
