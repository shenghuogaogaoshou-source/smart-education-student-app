# 🎬 脑洞放映厅 · 幻想制片厂

> 面向**中小学生**的"人工智能通识教育"创作游戏:抽卡 → 讲想法 → 写剧本 → 定画风 → 画分镜 → 首映礼。
> **当前版本不接任何 AI 接口**,全部离线可玩(影片用浏览器本地录制);以后要接模型,按下面的清单一项项启用。

---

## 🤖 装成安卓 App(.apk 安装包)

**手机上直接装(最省事)**:
```
1) 电脑:双击  启动手机模式.cmd        (保持窗口开着)
2) 手机:同 Wi-Fi 打开  http://电脑IP:8765/
3) 点页面右上角「📥 装安卓 App」→ 下载 bhfilm.apk
4) 手机上点安装(首次会提示"允许安装未知来源应用",允许即可)
5) 打开 App → 填教室服务器地址 → 开玩
```

**或者自己重新打包**:
```
app-android\构建APK.cmd     ← 双击;需要 Java 17 和 Android SDK(见下方"构建环境")
产物:app-android\脑洞放映厅.apk
```

**构建环境(已经在这台电脑装好)**:
| 部件 | 位置/版本 | 备注 |
|---|---|---|
| JDK 17 | `E:\java\jdk17` | **必须 17**:d8(打包 dex)在 JDK 25 上会崩 |
| Android SDK | `E:\android-sdk` | platform 34 + **build-tools 35.0.0**(34 的 d8 读匿名内部类会 NPE) |
| 构建脚本 | `app-android/build.sh` | 不用 gradle,全用 SDK 自带工具;中文路径会自动绕开(aapt2 不认) |

**App 行为**:首启填"教室服务器地址";连不上自动切内置离线版(抽卡/讲想法/走流程都能用);顶栏随时改地址。

- 安装包是**自己签名的**(教室里用足够;要上应用商店需要正式签名和备案)
- App 里的网页是**打包进去的**,所以图标、启动、界面都是本地秒开
- 想看/改 App 工程:`app-android/`(原生壳 `MainActivity.java` + 内置网页 `assets/` + `build.sh`)

## 📱 手机 PWA（安卓和 iPhone）

手机界面已加入统一安装入口、底部操作栏、可横向切换的创作步骤和离线状态提示。

- 正式安装：将公开前端资源部署到 HTTPS 地址，安卓 Chrome 使用「装到手机」，iPhone Safari 使用分享菜单中的「添加到主屏幕」。
- 局域网 HTTP 地址只能用于浏览预览，不能保证 PWA 安装和离线缓存。
- 首次联网打开，安装说明显示「离线资源已就绪」后，可以离线打开并使用本地创作功能。
- AI 生成与服务器作品备份需要后端在线；静态发布包只提供本地功能。
- 执行 `powershell -File build-pwa.ps1` 生成 `脑洞放映厅-PWA.zip`。详情见 `docs/PWA手机安装说明.md`。

## 👦 孩子的六步

| 步 | 做什么 | 学到什么 |
|---|---|---|
| 1️⃣ 抽脑洞卡 | 六个格子各抽一张:**主角 / 场景 / 经过**必抽,配角、转折、其他可选;还能**自己加新格子**、自己写卡 | 随机 + 取舍:先有素材,才有故事 |
| 2️⃣ 讲想法 | 上面是**卡拼出的故事简介**,下面补充细节:身世、伏笔、想去的方向 | 表达:越具体,后面越好办 |
| 3️⃣ 写剧本 | 小映给一份剧本草稿(**一行 = 一页分镜**),孩子随手改 | 结构:故事要分幕 |
| 4️⃣ 定画风 | 先给 **1 个最推荐**(⭐ 标出来),再给 **5 个备选**;都不喜欢就自己写 | 审美与选择 |
| 5️⃣ 画分镜 | 每页写"画面提示词" → 点「🖼️ AI 画这格」出真图;提示词写糊了会**翻车**(教学点),也可「🎨 重画这格」用免费画师 | **提示词工程** |
| 6️⃣ 首映礼 | 点**「🎬 生成影片 + 配音」**一条龙出片 → **先看片** → 起名字 → 写评论(最满意的一幕 / 还想改哪里)→ 存档 / 打印手册 | 反思与复盘 |

**两条铁律**:① 顶部步骤条任意跳转;② 回跳**绝不删孩子已经做好的东西**(只亮黄色提示条)。

## 🗂 项目结构

```
server.py        后端(零依赖):静态托管 + 作品备份(SQLite),不含 AI
index.html       六个屏幕:首页 / 抽卡 / 讲想法 / 写剧本 / 定画风 / 画分镜 / 首映礼
js/data.js       六类卡池(每类 50 张)+ 画风库
js/game.js       全部游戏逻辑(离线画师、影片录制、存档、打印)
css/style.css    界面样式
data/            运行时生成:bh.db(作品备份)、server.log
docs/工作流与接口.md   ★ 流程、接口、下一步接什么模型(给维护者)
tests/           smoke.js(前端 46 项)、api.js(后端 23 项)
```

## 🔌 已经接上的四个 AI 能力(Key 只在服务器,浏览器拿不到)

| 环节 | 用什么 | 模型 | 花费 | 在哪点 |
|---|---|---|---|---|
| ② 故事简介 | 智谱 GLM-5.2 | `glm-5.2` | ≈¥0.005/次 | 进「讲想法」自动把卡写成通顺的一段;也可点「✨ 让 AI 把简介写通顺」「🔁 换一版」 |
| ③ 写剧本 + 提示词润色 | 智谱 GLM-5.2 | `glm-5.2` | ≈¥0.01/部 | 讲想法→下一步 **自动让 AI 写剧本**(用卡+想法),孩子随手改;也可点「🔁 换一版」;分镜页「✨ 帮我把提示词写具体」 |
| ⑤ 画分镜 | 火山 Seedream 5.0 Lite | `doubao-seedream-5-0-260128` | ≈¥0.25/张 | 分镜页每格「🖼️ AI 画这格」(每部最多 12 张) |
| ⑥ 生成影片 | 火山 Seedance | 自动挑账号**已开通**的(优先 2.0 mini) | ≈¥1.5/条(5 秒) | 首映礼最上面「🎬 AI 生成影片(剧本+画面)」 |
| 配音 | 智谱 GLM-TTS | `glm-tts` | ¥2/万字符 | 首映礼「🎬 本机录制」自动用 AI 配音;不配 Key 就用浏览器朗读 |

- 顶部有一排 **AI 片场徽章**(编剧/润色/画师/影片/配音),绿色 = 已通,灰色 = 没配 Key
- **顶部徽章是实时的**:绿=能用,**⛔=这台电脑连不上那家服务**;悬停会说明原因
- 本机已配置走代理(Clash 7890):`.env` 里 `HTTPS_PROXY=http://127.0.0.1:7890`。**开游戏前请确认代理软件在运行**——火山方舟(画分镜/影片)要靠它才能连上;智谱不需要也行
- 火山不通时:画分镜可先用「🎨 重画这格」免费画师;要恢复 AI 出图,换 DNS 或在 `.env` 填 `HTTPS_PROXY` 后重启
- 出问题先看 `data/server.log`:每次 AI 失败都会写上一行(哪个环节、上游报什么错)
- 想让某个环节省钱,就在 `.env` 里把对应 Key 留空;游戏自动退回离线做法(整理模式草稿 / 程序化插画 / 浏览器朗读)
- **影片模型**:代码里按 `2.0 mini → 2.0 fast → 1.0 pro fast → 1.0 pro` 依次尝试,哪个开通了用哪个
  - 你账号目前 **Seedance 2.0 Mini 还没开通**(报 `ModelNotOpen`),所以现在实际跑的是 `doubao-seedance-1-0-pro-fast-251015`
  - 想用 2.0 Mini:火山方舟控制台 →「开通管理」→ 找到 `doubao-seedance-2-0-mini-260615` 点开通,**不用改任何代码**,下次生成影片自动用它
- `?demo=1` 加在网址后面 = 强制离线(测试/断网课堂用)

## 🚧 已知边界

- 影片是浏览器本地录制的 `.webm`(Edge/Chrome 可播);需要 MP4 可用剪映等转一下

- 不收集任何个人信息:只有"导演名 + 班级"式的昵称
