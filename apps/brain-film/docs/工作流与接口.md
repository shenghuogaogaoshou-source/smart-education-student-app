# 脑洞放映厅 · 工作流 / 接口 / 下一步接什么模型

> 给老师与维护者的一页纸。
> **当前版本 v4:已接入四个 AI 能力**(写剧本/润色、画分镜、生成影片、配音),Key 全部留在服务器;
> 把 `.env` 里的 Key 留空即可退回全离线模式。

---

## 一、这是什么

面向**中小学生**的"人工智能通识教育"创作游戏:孩子抽卡拼出故事、自己补细节、改 AI 写的剧本草稿、选画风、写提示词画分镜,最后在首映礼上看片、起名、写评论。

- **纯前端 + 轻后端**:`index.html + js/` 是全部游戏;`server.py` 只做静态托管与作品备份(零依赖 Python)
- **完全离线可玩**:双击 `index.html` 就能玩;影片用浏览器本地录制
- **作品归孩子**:存在本机浏览器,可选备份到本机服务器

---

## 二、六步工作流

| 步 | 屏幕 | 孩子做什么 | 系统做什么 |
|---|---|---|---|
| 1️⃣ | 🎴 抽脑洞卡 | 六个格子各抽一张:**主角 / 场景 / 经过**(必抽)、配角 / 转折 / 其他(可选);可**自己加格子**、可自己写卡、可换牌 | 每类 50 张卡池(`js/data.js` 的 `SLOT_DEFS`) |
| 2️⃣ | 💭 讲想法 | 上面显示**卡拼出的故事简介**,下面自由补充(身世/伏笔/方向) | `synopsisText()` 拼简介 |
| 3️⃣ | 📜 写剧本 | 读草稿、随手改(**一行 = 一页分镜**)、可"重新整理草稿" | `ideaToStoryDraft()`:离线只做"整理",一个字不编 |
| 4️⃣ | 🎨 定画风 | 从 3 个推荐里选,或自己写一个 | `recommendStyles()`:关键词打分(本地规则,不联网) |
| 5️⃣ | 🎬 画分镜 | 每页写台词 + **画面提示词** → 出图 → 改咒语重画 → 这版通过 | 程序化插画 `buildSVG()`;提示词写糊了会**翻车**(教学点) |
| 6️⃣ | 🌟 首映礼 | 一键「🎬 生成影片 + 配音」→ **先看影片** → 起名字 → 写评论(最满意的一幕 / 还想改哪里)→ 存档 / 打印 / 导出 | `makeFilm()`:canvas + MediaRecorder 把剧本+分镜录成 `.webm` |

**两条贯穿规则**(`refreshStepbar()` / `jumpTo()` / `syncDownstreamNotes()`):
1. 顶部步骤条**任意跳转**(没内容的那步不给跳)
2. 回跳/改前面**绝不删已有内容**,只亮黄色提示条,由孩子决定要不要重做

## 三、后端接口(v3,只有静态 + 作品备份)

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/health` | 健康检查(带版本、运行时长、备份作品数) |
| GET | `/api/config` | 告诉前端:`ai: false`、有哪些特性 |
| GET | `/api/works` | 作品备份列表 |
| POST | `/api/works` | 作品入库(upsert,单份 ≤25MB) |
| GET | `/api/works/<id>` | 读一份备份 |
| DELETE | `/api/works/<id>` | 删一份备份 |
| GET | 其它路径 | 静态文件(`.env`、`data/bh.db`、`server.log` 一律 **404**,不通过 HTTP 暴露) |

其它细节:默认只绑 `127.0.0.1`(`--lan` 才开机房模式)、每 IP 240 请求/分钟、单作品 25MB 上限。

## 四、数据与存档

```
浏览器                                        服务器(可选)
G(内存状态:slots/idea/story/style/panels)     data/bh.db
  ↕ localStorage                                 works 表(作品 JSON)
  bh_draft    未完成的草稿(刷新不丢)
  bh_archive  我的作品库(≤24 部)
```

- `.bhfilm` 导出 = 一份作品的 JSON;打印手册走 `printFilm()`(浏览器打印成 PDF)
- 影片是浏览器录的 `.webm`,存在内存里(刷新页面需要重新生成)

## 五、四个 AI 能力与接口(Key 只在服务器)

| 环节 | 模型 | 前端调用 | 服务端实现 |
|---|---|---|---|
| 故事简介 | 智谱 `glm-5.2` | `POST /api/synopsis` `{cards,idea}` → `{synopsis}` | 进「讲想法」自动调用;卡片一变就重写 |
| 写剧本(含润色) | 智谱 `glm-5.2` | `POST /api/story` `{cards,idea,old}` → `{lines}` | `zhipu_chat()`;`thinking:{type:disabled}` |
| 提示词润色 | 智谱 `glm-5.2` | `POST /api/polish` `{cap,prompt,style}` → `{prompt}` | 同上,温度 0.7 |
| 画分镜 | 火山 `doubao-seedream-5-0-260128` | `POST /api/image` `{prompt}` → `{src}` | `draw_image()`;尺寸 2560×1440(≥368 万像素),带 negative_prompt 去文字 |
| 生成影片 | 火山 Seedance(自动降级) | `POST /api/video` `{prompt,image,duration}` → `{taskId,model}`;`GET /api/video/<id>` → `{status,videoUrl,cost}` | `submit_video()` / `poll_video()`;`POST /v3/contents/generations/tasks` |
| **合成成片** | 本机 **ffmpeg** | `POST /api/film` `{videoUrl,lines,title}` → `{url}`;`GET /api/films/<id>.mp4`(支持 Range) | 下载 Seedance 片源 + GLM-TTS 旁白 → 画面不够长就循环 → 一条带配音的 mp4 落在 `data/films/` |
| 视频配音 | 智谱 `glm-tts` | `POST /api/tts` `{text}` → wav 二进制 | `tts()`;只支持 `wav`/`pcm` |

**影片模型顺序**:`doubao-seedance-2-0-mini-260615` → `2-0-fast` → `1-0-pro-fast-251015` → `1-0-pro-250528`,遇到 `ModelNotOpen / NotFound / not activated` 自动换下一个。
你账号目前只开通了 1.0 系列,所以实际用的是 `doubao-seedance-1-0-pro-fast-251015`;**要在控制台「开通管理」里开通 2.0 Mini 后,无需改代码即会自动升级**。

**依赖**:合成配音需要本机有 `ffmpeg`(已在 PATH 里即可);没有的话会自动跳过配音,只出无声画面。

**排错**:任何 AI 调用失败都会写进 `data/server.log`(格式:`❌ 模块 失败:上游报错`)并记进 `usage` 表;前端也会在对应的格子/按钮旁直接显示错误原文。

**成本闸(服务器侧硬闸)**:出图 ≤12 张/部 · 配音 ≤300 字/段 · 视频 ≤30 条/天 · 每 IP 240 请求/分钟 · 单作品 ≤25MB · 同尺寸失败自动换 2K 重试。

**三条铁律**:① Key 只放 `.env`,浏览器拿不到;② 所有模型请求带 `thinking:{"type":"disabled"}`(GLM-5.x / Seed 2.x 默认开思考,会把 4 秒拖到 36 秒);③ 失败不扣额度、不写进孩子的作品。

## 五点五、手机 App 形态(PWA)

| 部件 | 文件 | 说明 |
|---|---|---|
| App 清单 | `manifest.webmanifest` | 名称、竖屏、主题色、图标(192/512,含 maskable) |
| 离线缓存 | `sw.js` | App 外壳缓存优先;`/api/*` 一律走网络(不缓存 AI 结果和作品) |
| 图标 | `icon-192.png` / `icon-512.png` | 紫色圆角方块 + 播放键,纯 Python 生成 |
| 安装入口 | 顶栏「📲 装到手机」 | 支持 `beforeinstallprompt` 的浏览器会直接弹安装;iOS 给出手动步骤 |

**手机访问**:`python server.py --lan`(或双击 `启动手机模式.cmd`)→ 手机同 Wi-Fi 打开 `http://电脑IP:8765/` →「添加到主屏幕」。
**注意**:Service Worker 只在 `localhost` 或 **HTTPS** 下生效;局域网走 http 时缓存不启用(游戏仍可玩,只是不离线),这正是 `--lan` 场景下的已知限制。

**界面移动化**:`.stage` 单列、底部固定操作栏(拇指可达)、输入框 16px 防 iOS 缩放、`env(safe-area-inset-*)` 适配刘海屏、抽卡台两列、长按拖动用 Pointer Events(触屏上 HTML5 拖拽不触发)。

## 五点六、安卓 App(.apk)

`app-android/` = 原生壳 + 内置网页:

| 文件 | 作用 |
|---|---|
| `AndroidManifest.xml` | `com.bhfilm.app`;`usesCleartextTraffic` 允许连 http 内网;竖屏;`minSdk 24 / targetSdk 34` |
| `src/com/bhfilm/app/MainActivity.java` | WebView 壳:首启弹「教室服务器地址」;连不上自动 `file:///android_asset/index.html` 离线版;顶栏点一下可改地址 |
| `assets/` | 打包进去的网页(离线可开) |
| `build.sh` / `构建APK.cmd` | 一键打包:aapt2 → javac → d8 → zipalign → apksigner,产物 `脑洞放映厅.apk` |
| `bhfilm.apk`(项目根) | 同一个包,ASCII 名字,供手机从 `http://电脑IP:8765/bhfilm.apk` 直接下载安装 |

**踩过的坑**(改构建脚本别踩回去):① `d8` 在 JDK 25 会 NPE → 用 `E:\java\jdk17`;② build-tools **34 的 d8 读匿名内部类会崩** → 用 35.0.0;③ aapt2 **不认中文路径** → `build.sh` 自动搬到 `%TEMP%\bhapp-build` 里构建再拷回;④ `cmd //c` 里带引号的命令会被 MSYS 拆开 → 写成 `.bat` 再调用。

## 六、常见问题

| 症状 | 处理 |
|---|---|
| 打开是旧界面 | 浏览器缓存;js/css 已带版本号(`?v=`),再不行 Ctrl+F5 |
| 双击 index.html 能玩吗 | 能。只是没有作品备份、影片要在浏览器里录制 |
| 影片生成失败 | 需要 Edge/Chrome;页面会直接告诉你原因 |
| 提示词写得很细还是"翻车" | 已改成确定性:提示词为空或过短才翻车;写够 6 字以上就不再翻车 |
| 画分镜/影片报「连不上火山方舟」 | 这台电脑解析/直连 `ark.cn-beijing.volces.com` 不通(网络问题,不是程序问题)。**本机已配 `HTTPS_PROXY=http://127.0.0.1:7890`(Clash),开游戏前确保代理在运行**;没代理时可换 DNS(223.5.5.5)或临时用「🎨 重画这格」的免费画师。顶部徽章会 ⛔ 标出哪一项不通 |
| 想清空数据 | ⚙️ 片场设置 → 清空本机所有数据;服务器上的删 `data/bh.db` |
| 想给学生机共享 | `python server.py --lan`,学生机开 `http://老师电脑IP:8765/` |
