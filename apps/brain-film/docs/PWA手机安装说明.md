# 脑洞放映厅手机 APP

安卓和 iPhone 共用 PWA 版本，无需安装 APK。顶部「装到手机」提供安装入口；安装后从手机桌面图标打开，进入独立应用窗口。

## 安装

1. 把发布包解压到支持 HTTPS 的静态网站，完整保留 js、css、图标和离线脚本。
2. 安卓用 Chrome 打开正式地址，点击「装到手机」或浏览器菜单中的「安装应用」。
3. iPhone 用 Safari 打开，点击分享，再选择「添加到主屏幕」。
4. 首次联网打开后，在安装说明中确认「离线资源已就绪」。

电脑 localhost 只用于本机验证。手机不能通过电脑的 localhost 地址访问；同 Wi-Fi 的普通 HTTP 地址可以预览，但不满足正式离线安装要求。

## 使用

首页 → 抽卡 → 讲想法 → 写剧本 → 定画风 → 分镜 → 首映礼。手机底部提供当前步骤操作，顶部步骤条可横向滚动。作品库、设置和帮助保留在顶部。

离线时可以继续本地创作、抽卡、手改剧本和使用程序画师。AI 编剧、AI 图片、AI 视频、在线配音及服务器备份需要联网和对应后端服务；仅发布静态包不会自动提供这些服务。本机影片录制与朗读取决于设备浏览器支持情况。

草稿与作品保存在当前浏览器中，请通过作品导出功能备份重要内容。PWA 和浏览器的数据是否共享取决于系统，首次安装后请检查作品库。

## 更新与部署

运行 `powershell -File build-pwa.ps1` 重新生成公开静态包。只包含公开页面资源，不包含密钥、数据库、服务器日志和安卓签名文件。需要在线 AI 时应将 API 后端配置在同源 HTTPS 服务下。

更新页面资源时修改 sw.js 中的 CACHE 版本号，然后重新打包发布。新版本在旧应用窗口全部关闭后激活；index.html、sw.js 和 manifest.webmanifest 建议使用重新验证缓存策略。离线缓存只保存应用外壳，不保存 API 响应与用户作品。

原有安卓 APK 保留，但本次修改未重新打包进 APK。
