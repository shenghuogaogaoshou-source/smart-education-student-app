## 1. 项目概述

**AI Circuit Lab（AI 数字电路实验室）** 是一个运行于浏览器的可视化教学平台，用「拖拽 AI 元件 + 数据连线」的方式让学生理解**感知 → 判断 → 行动**的完整 AI 闭环。

- 核心理念：**搭电路一样搭 AI** — 把摄像头、语音识别、IF 判断、灯泡、机械臂都变成可拖拽的"电子元件"
- 真实运行：所有模块都是真实能力（Web Speech API、COCO-SSD 目标检测、Web Audio 合成音效…），非模拟
- 两种模式：**自由实验场**（任意组合）+ **关卡探险**（预设剧情化任务）
- 技术栈：React 18 + TypeScript 5 + Vite 5 + React Flow 11 + TensorFlow.js 4 + Zustand 4 + Tailwind CSS 3
- 手绘风格主题：蜡笔色、纸张质感、手写光标

## 3. 数据类型协议（DataType）

连线时**端口类型严格匹配**，类型不同无法相连。所有类型定义见 `src/types/circuit.ts`。

| 类型 id | 中文 | 代表内容 | 主题色 | 典型产生模块 | 典型消费模块 |
|---|---|---|---|---|---|
| `image` | 图像 | 一帧图像（Canvas） | `#6ba3c3` 蓝 | 摄像头、图片输入、场景相机、Text→Image（预览） | 感光器、目标检测、OCR（预览）、垃圾分类器 |
| `label` | 标签 | 有限类别中的**枚举分类名**（如「猫」「亮」「拍手」） | `#d4a04a` 金 | 感光器、目标检测、声音分类、垃圾分类器 | IF |
| `confidence` | 置信度 | 0~100% 的浮点概率 | `#a888c7` 紫 | 感光器、目标检测、声音分类 | 数值显示、文本拼接 |
| `signal` | 信号 | 布尔型 true/false 脉冲（Timer 是闪烁脉冲） | `#8aab6e` 绿 | IF、AND/OR/NOT、Timer、计数器、延时器、音量检测 | 灯泡、蜂鸣器、机械臂、LED、计数器 reset、TTS trigger |
| `text` | 文本 | **任意长度的自由文本**（句子、回答、识别结果） | `#8B5CF6` 紫 | 文本输入、语音识别、文本合并、LLM（预览）、OCR（预览） | 文字显示、TTS 播放器、文本合并、LLM（预览） |
| `number` | 数值 | 整数或小数（音量、计数、FPS、亮度…） | `#F97316` 橙 | 目标检测 count、音量检测、计数器 | 数值显示、文字显示、文本拼接 |
| `audio` | 音频 | 实时 MediaStream + RMS 音量 | `#3B82F6` 蓝 | 麦克风 | 语音识别、声音分类、音量检测 |

> ⚠️ **label vs text 的本质区别**：label 是「模型从固定枚举里挑出来的分类名」，text 是「任意人类可读的句子」；两者端口类型互不可连，除非通过 Text Merge 做桥接（详见 §6 FAQ）。

## 5. 数据流引擎与端口接线规则

### 5.1 数据包 Packet 格式
所有模块之间流动的数据都是 `Packet`（`types/circuit.ts`），每个包自带时间戳 `ts`：
```
image : { type:'image', canvas:HTMLCanvasElement, ts }
label : { type:'label', value:string, ts }
confidence : { type:'confidence', value:number(0~1), ts }
signal: { type:'signal', active:boolean, ts }  ← 上升沿/下降沿触发
text  : { type:'text', value:string, ts }
number: { type:'number', value:number, ts }
audio : { type:'audio', stream:MediaStream, level:number(0~1), ts }
```

### 5.2 求值链路
1. **上游模块** 通过 `circuitStore.emitPacket(id, outPortKey, packet)` 发包
2. **React Flow 画布** 的连接关系决定下游接哪个 `inPortKey`
3. **evaluator**（`evaluators.ts EVALUATORS[type]`）基于 inputs 计算 outputs + aiState
4. **下游组件** 从 `data.inputs[key]` 读取最新包，渲染 UI 并可能继续 emit

> 没有输入端口的模块（camera / microphone / textInput / timer / sceneCamera）直接在组件内部发包；有真实硬件/浏览器 API 的模块（speechRecognition / buzzer / tts / textDisplay）也在组件内部完成行为，evaluator 返回 `null` 或只更新 aiState 概览。

## 6. 关卡系统（Level System）

关卡系统代码位于 `src/levels/`，核心文件：
- `levelData.ts` — 关卡元数据 + 通关目标脚本 + 初始电路
- `LevelRunner.tsx` — 运行循环：检查通关条件、扣分、计时器、通关弹窗

- `LevelScenePanel.tsx` — 场景画面（海洋垃圾滚动）
- `SceneContext.ts` — 关卡场景状态

inputs[]    ← { id, label, type: DataType } 数组；无输入=[]

params[]    ← { id, label, type:'string'|'number'|'select', default, min?, max?, step?, options?, editable:true } 必须全
model?      ← 有真实模型的写上（COCO-SSD / Web Speech / ...）
explanation ← 教育性说明（面向学生的大白话，含为什么需要它 + 典型场景）
code()      ← 伪代码，引用参数做代入，展示真实 AI 的"等价代码"
levelOnly?  ← true = 仅关卡中出现

## 9. FAQ

### Q1. label（标签）和 text（文本）能不能互连？
不能。label 是有限分类枚举名，text 是自由句子，DataType 不同。想把 label 送文字显示，用 **Text Merge** 作为桥接器（模板「我看到了一只 {1}！」）。

### Q2. Timer 输出的是"真信号一直不灭"吗？
不是。Timer 输出**闪烁脉冲**：true 后立刻挂个 setTimeout 发 false（脉冲宽度约 400ms）。要持久真信号，用 AND + 自锁（或用 NOT + OR 组成 SR 锁存器）。

### Q3. 为什么语音识别必须连麦克风之后才启动？
Web Speech API 与 Microphone 模块都会调用 `getUserMedia`，两者同时请求会触发 Chrome 的 `not-allowed` 设备冲突。改为「麦克风先启动并授权 → 语音识别检测到 audio_in 已连接 → 再启动自己的识别引擎」，避免双重请求。

### Q4. 如何新增「自定义模块」？
侧边栏点击「创建自定义模块」即可编写 JavaScript 代码（运行在浏览器隔离沙箱里）。自定义模块的 `type` 以 `custom-` 为前缀，无需修改 `moduleRegistry.ts` / `evaluators.ts` / `nodes/index.ts`，也无需更新本文档 §4 表格。

---

**文档锚点**：新增模块时直接跳到 §4.1 ~ §4.5 中对应分类的表格末行追加，并在 §8 登记。
