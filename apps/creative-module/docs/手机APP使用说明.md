# 创造模块手机 APP（PWA）

## 操作

- 点击画布左上角「AI 模块市场」进入独立页面，搜索模块后点击「添加」，自动返回画布。
- 点击「返回画布」退出市场，不改变当前电路。
- 按住元件约 0.55 秒，打开屏幕下半部的元件检视器；移动手指会取消长按，保留拖动操作。
- 检视器内部可以滚动、修改参数、查看代码及删除元件。点击关闭、上方遮罩或按 Escape 退出。
- 单击元件只选中，也可通过画布顶部的检视按钮打开详情。
- 点击起点和终点接口完成连线；画布支持缩放和平移。
- 关卡模式同样使用独立模块市场与半屏检视器，手机上通过「任务提示」查看引导。

## 构建与发布

在项目目录运行 `npm run build`，生成的 `dist` 是完整静态发布目录，包含安装清单、图标、离线缓存脚本和本地模型。

将整个 `dist` 发布到支持 HTTPS 的静态网站根目录。请勿只上传 HTML 或 assets；models 和 images 也需要一起上传。本项目使用根路径资源，部署到子目录前需要调整资源路径与应用 scope。

本机可通过 `npm run preview -- --host 127.0.0.1` 检查正式版本。开发模式不注册离线缓存，避免缓存影响修改。电脑的 localhost 地址不能直接在手机上使用；手机安装需要可访问的 HTTPS 地址。

建议对 sw.js、index.html 和 manifest.webmanifest 设置重新验证缓存策略。新版离线缓存会在旧应用窗口全部关闭后生效，重新打开即可使用新版本。

## 手机安装

- 安卓：用 Chrome 打开正式 HTTPS 地址，点击应用顶部「安装」，或浏览器菜单中的「安装应用／添加到主屏幕」。
- iPhone：用 Safari 打开正式 HTTPS 地址，点击分享，选择「添加到主屏幕」。

安装后从手机桌面图标打开，以独立窗口运行。

## 离线与设备能力

应用外壳安装缓存完成后可离线打开。同源模型、关卡图片在离线缓存生效后的访问中逐步缓存；首次联网访问后，重新打开并使用相应功能，确保需要的资源已缓存。没有缓存的模型与图片仍需联网。外部模型源、在线语音服务等不承诺离线可用。

摄像头、麦克风需要用户授权和安全连接，具体能力由手机浏览器支持情况决定。当前交付已完成桌面浏览器手机尺寸的界面检查，尚未在安卓和 iPhone 真机上完成安装与硬件功能验收。
